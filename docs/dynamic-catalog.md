# کاتالوگ داینامیک و همگام با محصولات

## endpoint دانلود

کاتالوگ PDF همیشه از آخرین فهرست محصولات سایت تولید می‌شود و از این مسیر قابل دانلود است:

```text
GET /api/catalog.pdf
```

برای قرار دادن دکمه دانلود در رابط کاربری، کافی است لینک زیر استفاده شود:

```tsx
<a href="/api/catalog.pdf" download>
  دانلود کاتالوگ محصولات
</a>
```

## منبع داده

مولد کاتالوگ در حالت عادی از `PRODUCTS` در `src/data/productsData.ts` استفاده می‌کند؛ بنابراین متن‌ها، مشخصات، مدل‌ها و تصاویر `TS-*` سایت مستقیماً در PDF قرار می‌گیرند. اگر پنل ادمین داده محصولات را تغییر داده باشد، مقدار ذخیره‌شده در `admin_state` با کلید `products` اولویت دارد و همان داده در کاتالوگ استفاده می‌شود.

در نتیجه این مسیر با منطق فعلی `DataContext` همگام است: تغییرات محصولات از پنل ادمین در `admin_state` ذخیره می‌شوند و درخواست بعدی PDF آن‌ها را می‌خواند.

## قالب

صفحه‌آرایی کاتالوگ از ساختار پروژه `digital-catalog(1).zip` گرفته شده است: جلد، فهرست محصولات، صفحه مستقل برای هر محصول، تصویر، معرفی، مشخصات فنی، ویژگی‌ها و کاربردها. داده و تصاویر قدیمی `KT-*` از ZIP استفاده نمی‌شوند.

## رفتار تولید

PDF هنگام هر درخواست با Chromium headless تولید می‌شود و با `Cache-Control: no-store` ارسال می‌گردد؛ بنابراین فایل ذخیره‌شده روی سرور قدیمی نمی‌ماند. در صورت حجم بالای درخواست، می‌توان در مرحله بعد cache باطل‌شونده بر اساس زمان آخرین تغییر محصولات اضافه کرد.

## پیش‌نیاز اجرا

سرور باید Chromium را در مسیر زیر داشته باشد:

```text
/usr/bin/chromium
```

این مورد در محیط فعلی موجود و با `npm run lint` و تست endpoint تأیید شده است.
